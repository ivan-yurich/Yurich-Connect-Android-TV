# Синхронизация Android TV → Gitea

Workflow запускается при push в `main` публичного TV-репозитория и вручную
через вкладку Actions. Другие ветки, теги и релизы не входят в синхронизацию.
Зеркало обновляется обычным fast-forward, история не переписывается.

Для запуска нужен HTTP Deploy Token с записью только для приватного
`ivan-admin/Yurich-Connect-Android-TV`. Значение добавляется пользователем в
GitHub Actions Secrets TV-репозитория под именем `TV_GITEA_DEPLOY_TOKEN`.
Ни пароль, ни токен от учётной записи администратора не нужны.

До push проверяются все новые коммиты, включая боковых родителей merge.
Имена файлов APK/AAB/APKS/APKM/XAPK и подписи IDSIG блокируют весь перенос,
даже если следующий коммит удаляет такой файл. Произвольно переименованные
или вложенные файлы в архивах эта проверка не распознаёт.

При расхождении веток или сбое сети Gitea не перезаписывается принудительно.
После устранения причины запустите workflow вручную ещё раз. Для отключения
отключите **Sync TV main to Gitea** во вкладке Actions; при окончательном
отключении отзовите HTTP Deploy Token на Gitea. Содержимое веток не удаляйте.
