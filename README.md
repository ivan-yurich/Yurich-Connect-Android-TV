# Yurich Connect TV

Самостоятельное приложение для Android TV и Google TV (Android 7.0+, ARM32 и ARM64).
Оно использует собственный package ID `online.dnsai.ivanvpn.tv`, отдельную нумерацию
версий и собственный канал релизов. Телефонный APK здесь не собирается.

Экран рассчитан на пульт: импорт подписки по ссылке, выбор профиля, VPN,
Smart Route, Auto DNS и локальная диагностика. Встроенной установки обновлений
нет. Кнопка «GitHub» открывает только [страницу релизов TV](https://github.com/ivan-yurich/Yurich-Connect-Android-TV/releases).

## Проверка и сборка

Нужны Flutter 3.41.9, JDK 17, Android SDK 36 и NDK, используемый Flutter.
Из корня этого проекта:

```powershell
flutter pub get --enforce-lockfile
flutter analyze --no-pub
flutter test --no-pub
flutter build apk --release --flavor tv --target-platform android-arm,android-arm64 --no-pub
```

Без собственного локального release-подписанта результат предназначен только
для проверки сборки. Ключи, `android/key.properties`, APK, профили и логи
не должны попадать в историю Git. Для публикации используйте отдельный TV-ключ
и имя `YurichConnect-android-tv-v<версия>.apk`, никогда не имя телефонного APK.

## Переход со старой TV-версии

Новая версия ставится рядом со старой: Android хранит их настройки и данные
раздельно. Добавьте подписку в новой версии и подтвердите разрешение Android VPN.
Не удаляйте старую версию и не меняйте её системную блокировку, пока не проверили
новую. На устройстве одновременно работает только один VPN.

Исходный снимок общего ядра: commit `0ccfebe314f3548e0ce054460f1a740ce7597d7a`.
Плагин и нативные библиотеки находятся внутри этого репозитория; доступ к
телефонному репозиторию для сборки не нужен.
